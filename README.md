# Soupercussion portfolio

Ready for GitHub Pages. No build step required.

1. Create a public GitHub repository named `soupercussion`.
2. Extract this ZIP. Upload the contents, keeping `index.html` at the repository root and the `assets` folder intact. Include `.nojekyll`.
3. In Settings > Pages select Deploy from a branch, then `main` and `/ (root)`. Save.
4. GitHub shows the published address: https://YOUR-USERNAME.github.io/soupercussion/ . Publishing may take up to 10 minutes.

The site includes English/French switching, videos, SoundCloud, gallery and booking links. A free GitHub Pages deployment uses a public repository: source and included media are publicly accessible. A custom domain is optional and purchased separately.

Documentation: https://docs.github.com/en/pages/quickstart
